# 每日记账（Meiri Jizhang）

一个完全在您自己电脑上运行的 Windows 个人记账桌面应用：记一笔账不超过 10 秒，随时看清钱花在了哪里、每月结余多少。

- **单机使用**：无需注册登录，不联网，账单数据只保存在您自己的电脑上
- **上手即用**：内置 16 个大科目、76 个子类科目，贴近真实生活
- **界面直观**：全中文日常用语，非技术人员也能立刻上手

## 功能特性

### 核心功能

| 功能 | 说明 |
| --- | --- |
| 记一笔 | 选类型（支出/收入）→ 两级分类 → 填金额和日期，备注可选，10 秒完成 |
| 账单流水 | 按时间倒序查看全部账单，按天分组并自动小计 |
| 编辑与删除 | 随时修改或删除记错的账目（删除有二次确认） |
| 分类管理 | 增删改支出/收入的大科目与子类，可调整显示顺序 |
| 今日概览 | 首页一眼看到今日收入、支出与结余 |
| 月度汇总 | 按月查看收入、支出与结余 |

### 增强功能

- **统计图表**：分类占比环形图 + 近 12 个月收支趋势折线图（配色已通过色盲可区分性校验）
- **预算提醒**：设置每月支出预算，达 80% 黄色提醒、超支红色提醒，进度条实时可见
- **搜索筛选**：关键词、收支类型、大科目、日期范围、金额区间六条件自由组合查找账单

### 预置分类体系

内置贴近真实生活的两级分类（16 个大科目、76 个子类），例如「餐饮 → 早餐/外卖/咖啡奶茶…」「交通 → 公交地铁/打车/加油…」，并可在分类管理页自由增删改。完整分类清单见 [记账app/CLAUDE.md](记账app/CLAUDE.md) 第四章。

## 界面

| 页面 | 内容 |
| --- | --- |
| 今日记账（首页） | 今日收支结余、醒目的「记一笔」按钮、今日账单列表 |
| 账单流水 | 按月切换、按天分组的历史账单，带搜索与筛选 |
| 统计 | 月度汇总、预算进度、分类占比环形图、12 个月收支趋势 |
| 分类管理 | 支出/收入两页签，增删改大科目与子类、调整顺序 |
| 设置 | 月度预算设置、账单数据文件位置说明 |

## 安装与使用

Windows 安装程序由源码构建生成（不随仓库分发）：

```bash
cd 记账app
npm run build:win
```

构建产物位于 `记账app/dist/`，双击安装、无需管理员权限、自动创建桌面快捷方式。软件未做商业签名，首次运行若 SmartScreen 弹窗，点「更多信息 → 仍要运行」即可。

## 数据存储与安全

- 账单数据保存在本机 `%APPDATA%\meiri-jizhang\meiri-jizhang.db`（SQLite 数据库），与软件安装位置无关，卸载软件不会删除账单
- 金额一律以「分」为整数存储（28.50 元 = 2850），避免小数计算误差
- 本仓库只包含程序代码与文档，**不含任何账单数据**；软件完全不联网

## 技术栈

- Electron 39 + electron-vite 5（桌面应用框架与工程工具）
- React 19 + TypeScript（界面）
- ECharts 6（统计图表）
- node:sqlite（Electron 自带 SQLite 引擎，零额外原生依赖）
- electron-builder + NSIS（Windows 安装包）

## 项目结构

```
记账app/
├── src/
│   ├── main/          # 主进程：SQLite 数据库、账单/分类/预算业务逻辑、IPC 接口
│   ├── preload/       # 安全桥接层：把主进程接口暴露给界面
│   ├── renderer/      # 界面：五个页面与通用组件（React）
│   └── shared/        # 主进程与界面共享的类型与日期工具
├── build/             # 应用图标等构建资源
├── electron-builder.yml
└── CLAUDE.md          # 完整项目文档（产品定位、分类体系、技术方案、开发约定）
```

## 开发
