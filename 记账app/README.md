# 每日记账

Windows 个人记账桌面应用（Electron + React + TypeScript）。

> 项目完整介绍见仓库根目录 [README.md](../README.md)；产品与技术总纲见 [CLAUDE.md](CLAUDE.md)。

## 常用命令

```bash
npm install          # 安装依赖
npm run dev          # 启动开发模式
npm run typecheck    # 类型检查
npm run lint         # 代码规范检查
npm run build:win    # 构建 Windows 安装包（产物在 dist/）
```
